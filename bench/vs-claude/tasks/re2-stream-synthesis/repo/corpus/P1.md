# P1 - "Windowed sequence models for streaming logs" (fictional, 2025)
We argue that fixed sliding windows are necessary for streaming anomaly detection: removing the window module lowered F1 by 7-12 points on three benchmarks. Our model, WinSeq, feeds 64-event windows to a GRU. On SPR-Y (full split) WinSeq reaches F1 0.884; on OSK-Y it reaches F1 0.839. Training uses 70% labeled data.
