# P4 - "Windowless detection: every event counts" (fictional, 2026)
Contrary to the view that windowing is required, we show that a windowless model (EvtNet) matches or exceeds windowed models: on SPR-Y (full split) EvtNet obtains F1 0.903 versus 0.884 for WinSeq. Window boundaries split causal event chains and hurt recall. Training uses 70% labeled data.
