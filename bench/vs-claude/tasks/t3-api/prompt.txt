Hiện thực đầy đủ 4 tính năng trong FEATURES.md cho API quản lý nhiệm vụ này (xác thực & phân quyền, lọc/tìm/sắp xếp/phân trang, xuất CSV, nhật ký thao tác). Bám sát từng quy tắc của đặc tả (mã lỗi, thứ tự kiểm tra, định dạng CSV) — bộ nghiệm thu ẩn sẽ gọi API thật qua HTTP để kiểm tra. Cập nhật test có sẵn cho hợp với dạng kết quả mới, thêm test cho từng tính năng, đảm bảo `npm test` xanh. Không thêm thư viện ngoài.
