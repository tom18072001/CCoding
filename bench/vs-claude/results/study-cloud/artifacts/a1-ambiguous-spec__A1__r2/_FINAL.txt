**Four contradictions in the customer request**

The spec resolves each one with the safest default. All four are listed under `## Open questions and assumptions` (Q1, Q3, Q7, Q8):

1. **Unmasked data vs. "no personal data unmasked".** The default export is masked: the last IP octet is hidden and usernames become keyed pseudonyms. Full IPs and usernames come only from a separate forensic export. That export needs its own permission, a justification, a second approver and an encrypted single-use link. It also expires.
2. **"Kept forever" vs. "delete personal data after 12 months".** The 12-month deletion wins for every export file that contains personal data. Only an audit record with no personal data is kept indefinitely: export ID, hash, scope, requester, approver and timestamps.
3. **"Export everything they can see" vs. "team, last month".** The scope is the manager's team for the previous calendar month in Vietnam time (UTC+7). Viewer permissions are only an upper bound.
4. **5 seconds vs. unknown data volume.** The 5-second target applies to exports up to 100,000 rows. Larger exports run in the background and the user is notified.
