**Assumptions the spec left open** (change them if your acceptance suite differs)
- **Timestamps:** a `T` separator is required, so date-only strings and `"2024-01-01 10:00"` don't produce `@t`.
- **`msg` fallback:** a `msg` that is `null` counts as absent, so `message` is used.
- **Error positions the spec doesn't cover:**
  - An invalid field name before `:` reports the token start.
  - A `)` where an operand is expected reports that `)`.
  - Errors are reported leftmost-first.
- **Bucket keys:** `1` and `"1"` are separate buckets in `count by`.
- **Aggregation specs:**
  - The field name must match the field regex, otherwise the spec is invalid.
  - Histogram intervals are normalized, so `05m` becomes `5m`.
- **CLI:**
  - `--opt=value` is accepted.
  - `--` ends option parsing.
  - Usage and query errors (exit 2) are detected before any file is read, so they win over a missing file (exit 1).
  - A leading BOM in input is stripped.
