## Tóm tắt
Phần lớn đặc tả đã được hiện thực đúng: parse, ISO 8601, làm tròn half away from zero, `largest` kèm nhớ, và test biên đầy đủ. Tôi đọc `SPEC.md`, `src/duration.js` và `test/duration.test.js` và không thấy lỗi logic nào ở các mục này. Tôi không tự chạy `npm test` (chỉ đọc), nên kết quả xanh dựa trên log CCoding trong báo cáo: 10/10 pass, exit 0. **Chưa nghiệm thu** vì có một chỗ lệch nhỏ so với đặc tả: message lỗi khi input là `function` hoặc `symbol`.

## Rủi ro & việc còn mở
- **Thấp:** lệch message ở input kiểu function/symbol như mô tả trên. Bộ nghiệm thu ẩn ít khả năng kiểm tra, nhưng nó trái đặc tả chữ nghĩa.
- **Rất thấp:** input `BigInt` làm `JSON.stringify` ném lỗi. Code vẫn trả `TypeError`, nhưng message là `String(input)`.
- **Giả định:** `npm test` xanh chỉ dựa trên log CCoding, tôi không tự chạy lại.

## Việc tiếp theo
- **Sửa message lỗi cho input không JSON-hóa được** · Trong `fail()`, khi `JSON.stringify` trả `undefined` thì dùng đúng chuỗi `"undefined"`. Thêm test với function và symbol · @senior-swe · Xong khi `npm test` xanh và các test mới pass.
