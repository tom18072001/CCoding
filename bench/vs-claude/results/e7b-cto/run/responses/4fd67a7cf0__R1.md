## Rủi ro & việc còn mở
- **Lỗi hồi quy (cao):** `GET /tickets/:id` trả 404 với mọi id. Đề bài nói client mobile và web đang dùng API hiện có, nên nếu họ gọi route này thì sẽ hỏng ngay.
- **Review chưa bắt được lỗi:** cổng chất lượng duyệt tự động dựa trên test xanh. Phần review chỉ đối chiếu `npm test`, không đọc diff.
- **Test thiếu:** chưa có test cho `GET /tickets/:id` và chưa có test cho trường hợp tham số lặp, tức là giá trị không phải chuỗi (mảng). Code có xử lý các trường hợp này (`str`) nhưng không có test chứng minh.
- **Giả định:** các đường nhánh cursor giả mạo ngoài các ca đã test (ví dụ giá trị `v` sai kiểu) chỉ được đọc code, chưa chạy thử.

## Việc tiếp theo
- **Sửa hồi quy `/tickets/:id`**: khôi phục `req.method === 'GET'` ở `src/handler.js:83`, thêm test cho GET 200, id không tồn tại 404, và non-GET 404. Việc này do `@senior-swe` làm, xong khi `npm test` xanh và test mới fail trên code cũ.
