## Tóm tắt

Chưa nghiệm thu. Logic cửa sổ trượt và cooldown trong `src/alert.js` đúng theo đề bài. Tuy nhiên bộ so sánh sắp xếp host (`src/alert.js:31`) sai, nên thứ tự alert cùng `ts` khác nhau giữa các host sẽ sai. Báo cáo ghi `npm test` xanh, nhưng chỉ có 1 test và test đó không phủ trường hợp này. Tôi không chạy lại được `npm test` hay script thử vì lệnh bash bị chặn chờ duyệt. Các kết luận dưới đây dựa trên đọc mã và trên số liệu trong báo cáo.

## Tiêu chí nghiệm thu

| Tiêu chí | Kết quả | Bằng chứng |
|---|---|---|
| Chỉ tính sự kiện 5xx (500–599), tách riêng từng host | Đạt | `src/alert.js:8-13` gom theo host, lọc `status >= 500 && <= 599`. |
| Cửa sổ nửa mở `(ts - windowMs, ts]`, đếm đúng `count` | Đạt | `src/alert.js:22` dùng `ts[start] <= t - windowMs` để loại phần tử, `count = i - start + 1` ở dòng 23. |

| Xuất ES module đúng chỗ | Đạt | `export function detectBursts` trong `src/alert.js`. |
